Resumo executivo — causa raiz
- Erro TS2589 (“Type instantiation is excessively deep and possibly infinite”) vem da inferência/instanciação de tipos ao redor do wrapper asResolver + zodResolver/react-hook-form. O TypeScript está expandindo tipos complexos retornados por zodResolver e pelo wrapper, gerando recursão/excesso de profundidade.
- Solução correta e definitiva: evitar que a inferência do TypeScript re-expanda o tipo complexo. Isso é feito tipando o wrapper asResolver com a assinatura genérica adequada (Resolver<T>) de forma que o chamador forneça explicitamente TFormValues e o compilador não tente re-inferir a partir do valor complexo. NÃO usar casts “any” permanentes nos componentes (isso só mascara o problema).

```ts
// Caminho no repo: src/lib/form-helpers.ts
// Tipagem robusta para evitar inferência recursiva ao usar asResolver<...>(zodResolver(...))

import type { Resolver, FieldValues, ResolverResult } from "react-hook-form";

/**
 * asResolver: wrapper tipado que preserva a tipagem TFormValues sem forçar o compilador
 * a re-inferir tipos complexos retornados por libs (ex: zodResolver).
 *
 * Uso:
 *   resolver: asResolver<MyFormData>(zodResolver(myZodSchema))
 *
 * Explicação:
 * - Recebe um Resolver já existente e o re-expõe tipado como Resolver<TFormValues>.
 * - Ao fornecer explicitamente TFormValues no chamador, TypeScript NÃO tenta expandir a
 *   estrutura interna do resolver (que é a fonte do estouro de instância de tipo).
 */
export function asResolver<TFormValues extends FieldValues = FieldValues>(
  resolver: Resolver<TFormValues>
): Resolver<TFormValues> {
  return resolver as Resolver<TFormValues>;
}
```
