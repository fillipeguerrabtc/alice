The job failed while trying to push a Docker image to GitHub Container Registry (ghcr.io) due to permissions issues:

```
ERROR: failed to push ghcr.io/fillipeguerrabtc/alice-auth:81bf96659633134ec42cbe7d2433c8ab16c20f02: denied: permission_denied: write_package
```

## Solution

1. **Check GitHub Token Permissions**
   - Ensure that the GitHub Actions workflow is using a token (`GHCR_TOKEN`, `GITHUB_TOKEN`, or a PAT) with the correct permissions.
   - The token must have `write:packages` and `read:packages` permissions for pushing Docker images.

   **Example: Use a Personal Access Token (PAT) as a secret (`GHCR_TOKEN`)**
   ```yaml
   - name: Log in to GitHub Container Registry
     run: echo ${{ secrets.GHCR_TOKEN }} | docker login ghcr.io -u ${{ github.actor }} --password-stdin
   ```

2. **Update Workflow Usage**
   - If you're using the default `GITHUB_TOKEN`, by default, it does not have `write:packages`.
   - In the repository settings, configure the `GITHUB_TOKEN` permissions under Settings > Actions > General > Workflow permissions.
     - Set to: "Read and write permissions"
     - Also, "Allow GitHub Actions to create and approve pull requests" (if relevant).

   **Example configuration:**
   - Go to your repo settings.
   - Set `Workflow permissions` to `Read and write`.

3. **Check the Package Permissions**
   - Make sure that your user (fillipeguerrabtc) or the token has access to write to the package repo: `ghcr.io/fillipeguerrabtc/alice-auth`.
   - Verify that the `alice-auth` package exists and your permissions are set to allow writes.

4. **Verify the Workflow Step**
   - Make sure your workflow YAML file (`.github/workflows/deploy-production.yml`) includes the login step before pushing the image.

   **Relevant snippet:**
   ```yaml
   steps:
     - name: Log in to GitHub Container Registry
       run: echo ${{ secrets.GHCR_TOKEN }} | docker login ghcr.io -u ${{ github.actor }} --password-stdin
   ```

   - Replace `${{ secrets.GHCR_TOKEN }}` with a valid PAT in your repo secrets if needed.

## Next Steps

- Add a PAT with package write permissions to your repo secrets as `GHCR_TOKEN`.
- Use it in your workflow for Docker login.
- Make sure the workflow is running with "Read and write" permissions for `GITHUB_TOKEN` if you want to use the default token.
