- This usually happens when complex generic types from react-hook-form + zodResolver are expanded by the compiler and cause excessive recursive type instantiation.

Quick, safe fix
- Narrow the resolver type by casting the zodResolver to react-hook-form's Resolver<T>. This prevents TypeScript from recursively expanding the resolver’s inferred generic types.
- Apply the same pattern to the other files that have the same error.

Code change example for the failing Agents.tsx
- File: apps/frontend-service/src/pages/Agents.tsx (ref: 5b464daafd08ba3f6a666a24ff24fcd171e930e8)
- Replace the useForm call to cast resolver to Resolver<AgentFormData>.

Patch (small diff):
1) Add the import:
```ts
import type { Resolver } from "react-hook-form";
```

2) Change the form initialization to cast the resolver:
```ts
const form = useForm<AgentFormData>({
  resolver: zodResolver(agentFormSchema) as unknown as Resolver<AgentFormData>,
  defaultValues: {
    nome: "",
    slug: "",
    descricao: "",
    instrucoes: "",
    personalidade: "",
    status: "active",
  },
});
```

Why this works
- The cast stops the compiler from trying to infer every nested generic inside the resolver, avoiding the "excessively deep" expansion while keeping type safety for your form data.
