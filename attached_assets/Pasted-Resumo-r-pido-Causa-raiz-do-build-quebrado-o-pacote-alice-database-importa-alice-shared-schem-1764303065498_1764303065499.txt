Resumo rápido
- Causa raiz do build quebrado: o pacote @alice/database importa '@alice/shared/schema' mas o pacote shared não está expondo essa subpath / não tem declarações compiladas/d.ts disponíveis antes do build do database. Resultado: tsc retorna TS2307 (Cannot find module '@alice/shared/schema').
- Solução: tornar o pacote shared um pacote TypeScript bem definido (declaration: true, composite), expor o subpath ./schema (ou ajustar imports no database), declarar dependência workspace no database, adicionar referências de projeto (project references) e garantir que o CI / Dockerfile compile o shared antes do database.

Abaixo estão todas as correções completas, com arquivos propostos e comandos. Aplique-as no repositório; elas resolvem o erro atual e melhoram robustez e ordem de build do monorepo.

Correções e melhorias (lista completa)
1) packages/shared: tornar pacote TypeScript publicável/consumível com declarações
- Habilitar declaration, composite, outDir, e criar index que re-exporte schema.

Arquivo proposto:
```json name=packages/shared/tsconfig.json url=https://github.com/fillipeguerrabtc/alice/blob/f656ac47a62f79b5b1ce3839e9cfb9b2639f483f/packages/shared/tsconfig.json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ES2020",
    "declaration": true,
    "declarationMap": true,
    "composite": true,
    "outDir": "dist",
    "rootDir": "src",
    "esModuleInterop": true,
    "skipLibCheck": true,
    "strict": true
  },
  "include": ["src/**/*"]
}
```


Por que essas mudanças resolvem o erro
- O TypeScript procura declarações do módulo importado. Se o pacote shared não gerar .d.ts (declaration) e não for exposto na forma de um pacote com main/types/exports, tsc não resolve '@alice/shared/schema' em outro pacote. Habilitar declaration + composite + exports + references garante que:
  - shared seja compilado primeiro,
  - produza .d.ts,
  - exponha subpath "./schema" para imports como '@alice/shared/schema',
  - pnpm ligue pacotes locais via workspace:*.
