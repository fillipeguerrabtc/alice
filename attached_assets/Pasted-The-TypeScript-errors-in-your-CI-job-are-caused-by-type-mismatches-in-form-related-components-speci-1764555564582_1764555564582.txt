**1. Fix TypeScript Type Instantiation/Infinite Errors**

Files affected (sample lines from logs):
- `client/src/lib/form-resolver.ts` (line 34)
- `apps/frontend-service/src/lib/form-resolver.ts` (line 34)

This often happens when using overly generic or recursive type definitions. Instead, use explicit types:

```typescript
// Instead of generic TFieldValues, use a concrete interface.
type AgentFormValues = {
  status: "training" | "active" | "paused" | "deprecated";

```

Use the explicit type in your resolver definitions:


**2. Remove Undefined from Required Properties**

Errors like:
> Type '"training" | "active" | "paused" | "deprecated" | undefined' is not assignable to type '"training" | "active" | "paused" | "deprecated"'.  
> Type 'string | undefined' is not assignable to type 'string'.

**Solution:**
- Do not include `undefined` in union types for required fields.
- If a field is required, declare it as non-optional.

Example for the Namespaces form:

```typescript
type NamespaceFormValues = {
  nome: string;
  slug: string;
  cor: string;                // Make this non-optional if required
  descricao?: string;
};
```
