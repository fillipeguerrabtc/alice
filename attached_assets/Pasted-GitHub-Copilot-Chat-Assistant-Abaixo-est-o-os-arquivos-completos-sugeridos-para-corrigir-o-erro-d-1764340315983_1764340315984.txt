1) packages/shared/tsconfig.json
Explicação: habilita "composite" e geração de declarações (.d.ts). Necessário para que outros projetos (database) possam referenciar o shared via tsc -b.

```json
{
  "compilerOptions": {
    "composite": true,
    "declaration": true,
    "declarationMap": true,
    "outDir": "dist",
    "rootDir": "src",
    "module": "commonjs",
    "target": "ES2020",
    "moduleResolution": "node",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["src/**/*"]
}
```

2) packages/shared/package.json
Explicação: garante que `types` aponta para o .d.ts gerado e define o script de build (tsc -b).

```json
{
  "name": "@alice/shared",
  "version": "1.0.0",
  "main": "dist/index.js",
  "types": "dist/index.d.ts",
```

6) package.json (root) — trecho recomendado
Explicação: script root para executar builds recursivos do workspace via pnpm. Use `pnpm -w -r --stream run build` para construir todos os pacotes respeitando dependências declaradas no package.json (workspace) e os references do TypeScript.

```json
{
  "name": "alice-monorepo",
  "private": true,
  "version": "0.0.0",
  "workspaces": [
    "packages/*"
  ],
  "scripts": {
    "build": "pnpm -w -r --stream run build",
    "build:tsc-root": "tsc -b tsconfig.build.json"
  },
  "devDependencies": {
    "typescript": "^5.2.0"
  }
}
```

7) Dockerfile (atualizado — multi-stage)
Explicação: no estágio builder instala dependências e executa um build do workspace inteiro (resolve ordem). No estágio runtime copia apenas artefatos necessários (ex.: packages/database/dist). Ajuste os COPY/ENTRYPOINT conforme sua app real.

```dockerfile
# --- Build stage ---
FROM node:20-alpine AS builder
WORKDIR /app

# Ativa Corepack e pnpm
RUN corepack enable && corepack prepare pnpm@latest --activate

# Copia arquivos de lock e package manifests primeiro para aproveitar cache
COPY package.json pnpm-workspace.yaml pnpm-lock.yaml ./

# Copia o resto do código
COPY . .

# Instala dependências do monorepo
RUN pnpm install --frozen-lockfile

# Build de todos os pacotes na ordem correta
RUN pnpm -w -r --stream run build
# ou, se preferir usar tsc -b do root:
# RUN pnpm install && pnpm run build:tsc-root

# --- Runtime stage (exemplo para serviço 'database') ---
FROM node:20-alpine AS runtime
WORKDIR /app

# Copia apenas os artefatos necessários (ajuste se precisar de mais pacotes)
COPY --from=builder /app/packages/database/dist ./packages/database/dist
# Se precisar do node_modules de runtime:
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./package.json

# Ajuste a porta e o comando conforme seu serviço
EXPOSE 3000
CMD ["node", "packages/database/dist/index.js"]
```
