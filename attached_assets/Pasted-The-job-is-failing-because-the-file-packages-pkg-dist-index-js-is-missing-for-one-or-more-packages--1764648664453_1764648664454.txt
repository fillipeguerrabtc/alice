The job is failing because the file packages/$pkg/dist/index.js is missing for one or more packages in your monorepo. The logs show a Bash script that checks for this file, and exits with an error if not found, displaying the message:

ERRO: packages/$pkg/dist/index.js não baixado!

This typically means the build step for that package did not complete successfully, or the build output was directed elsewhere.

## Solution

1. **Check the Build Step**  
   Ensure you're running the correct build command for each package before this step. For most setups, this involves running something like `npm run build` or `pnpm build` inside each package directory.

2. **Check for Output Directory**  
   Confirm that the build process actually produces a dist/index.js file. In package.json, look for a build script—if missing, add something like:

   ```json
   "scripts": {
     "build": "tsc"
   }
   ```

3. **Verify TypeScript Configuration**  
   If you’re using TypeScript, ensure tsconfig.json's outDir is set to "dist":

   ```json
   "compilerOptions": {
     "outDir": "dist"
   }
   ```

4. **Update the CI Workflow**  
   In .github/workflows/ci.yml, before file checks, add steps to build each package:

   ```yaml
   - name: Build all packages
     run: |
       for pkg in $(ls packages); do
         cd packages/$pkg
         npm install
         npm run build
         cd ../..
       done
   ```

5. **Commit a Dummy index.js if Needed**  
   If there are packages without source files (e.g., meta packages), create a placeholder dist/index.js to satisfy the check.

## Code Example for package.json

If a package is missing a build script, add this:

  "build": "tsc"
}

- Ensure the build actually creates dist/index.js.
