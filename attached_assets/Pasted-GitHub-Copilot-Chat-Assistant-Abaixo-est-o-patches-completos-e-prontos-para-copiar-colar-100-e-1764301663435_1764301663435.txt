9) Dockerfile — alteração crítica
Localize a linha que falhou no build (referência dos logs: ref 0c1efb96e924226c0e15188be9c99db2ae84f376, Dockerfile linha ~53). Substitua o comando que apenas builda database por uma construção de ordem correta.

Antes (problemática):
RUN pnpm --filter @alice/database run build

Substituir por (copiar/colar):
# Buildar shared primeiro, depois database (determinístico)
RUN pnpm --filter @alice/shared run build && pnpm --filter @alice/database run build

Alternativa mais robusta (build topológico de todos os workspaces, recomendado em ambientes enterprise):
RUN pnpm -w -r run build --if-present

Escolha a opção adequada ao seu Dockerfile. A primeira garante ordem explícita; a segunda faz build recursivo topológico.
