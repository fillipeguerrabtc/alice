3) Ajustar ou corrigir o healthcheck (se for ele o problema)
- Verifique o bloco healthcheck no docker-compose.prod.yml / Dockerfile do alice-chat.
- Exemplo de healthcheck robusto (docker-compose):

    test: ["CMD", "curl", "-f", "http://localhost:3000/health" ]
    interval: 30s
    timeout: 10s
    retries: 5

- Se a sua aplicação expõe outra rota/porta, ajuste /health e PORT. Se a app não tem endpoint HTTP, use um comando que valide a aplicação (ex.: checar processo ou arquivo PID).

Observação: se o healthcheck for um comando custom que falha por depender de DB ainda não pronto, substitua por um healthcheck que verifique só a própria app, e garanta que a app espere o DB (próximo item).

4) Garantir que o serviço espere o banco (ex.: Postgres) — adicionar wait-for-db
Causa comum: alice-chat tenta conectar ao Postgres antes do banco estar totalmente pronto => falha e healthcheck marca unhealthy.

Opções:
a) Usar um script "wait-for" na ENTRYPOINT que aguarda Postgres (pg_isready) — Exemplo de entrypoint/wait:
  # wait-for-postgres.sh
  #!/usr/bin/env bash
  set -e
  until PGPASSWORD="$POSTGRES_PASSWORD" pg_isready -h "$POSTGRES_HOST" -p "${POSTGRES_PORT:-5432}" -U "$POSTGRES_USER"; do
    echo "Aguardando Postgres em $POSTGRES_HOST:$POSTGRES_PORT..."
    sleep 2
  done
  exec "$@"

- Tornar o script executável e chamá-lo no Dockerfile / docker-compose command/entrypoint:
  ENTRYPOINT ["/app/wait-for-postgres.sh"]
  CMD ["node", "dist/index.js"]  # exemplo

b) Usar uma ferramenta wait-for-it.sh ou dockerize se preferir.

11) Exemplos de correção específicos
a) Exemplo de docker-compose.prod.yml (snippet com healthcheck e env):
  services:
    alice-chat:
      image: fillipe/alice-chat:${IMAGE_TAG}
      environment:
        - POSTGRES_HOST=alice-postgres
        - POSTGRES_PORT=5432
        - POSTGRES_USER=app
        - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
        - DATABASE_URL=postgres://app:${POSTGRES_PASSWORD}@alice-postgres:5432/alicedb
      depends_on:
        - alice-postgres
      healthcheck:
        test: ["CMD-SHELL", "curl -f http://localhost:3000/health || exit 1"]
        interval: 30s
        timeout: 10s
        retries: 5
      restart: unless-stopped

b) Exemplo de wait-for-postgres.sh (coloque em image ou montado no container):
  #!/usr/bin/env bash
  set -e
  echo "Aguardando Postgres..."
  until PGPASSWORD="$POSTGRES_PASSWORD" pg_isready -h "$POSTGRES_HOST" -p "${POSTGRES_PORT:-5432}" -U "$POSTGRES_USER" >/dev/null 2>&1; do
    sleep 2
  done
  echo "Postgres pronto. Inicializando app..."
  exec "$@"
