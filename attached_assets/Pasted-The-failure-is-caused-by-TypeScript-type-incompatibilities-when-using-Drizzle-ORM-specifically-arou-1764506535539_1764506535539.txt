The failure is caused by TypeScript type incompatibilities when using Drizzle ORM, specifically around the PgColumn, Column, and SQL types. The logs indicate errors like:

- "Type 'PgColumn<...>' is not assignable to type 'Column<...>'"
- "'shouldInlineParams' property is incompatible between types SQL<unknown>"

This usually happens when mixing objects or helpers imported from multiple instances of Drizzle ORM libraries (possibly due to hoisting, symlinked packages, or usage of pnpm with mismatched dependency trees).

**How to fix:**

1. **Ensure a Single Drizzle ORM Version:**
   - In your root `package.json`, make sure there is only one instance and version of the `drizzle-orm` package.
   - Remove all possible duplicate installations from `node_modules`.
   - Use:
     ```bash
     pnpm list drizzle-orm
     ```
     Ensure it reports only one version. If there are conflicts, use:
     ```bash
     pnpm dedupe
     pnpm install
     ```

2. **Check Your Imports:**
   - Make sure your imports from Drizzle ORM use the same module resolution path:
     ```typescript
     import { eq, and, desc, sql, isNull, not } from "drizzle-orm";
     ```
     Do not use paths like "@myorg/drizzle-orm" if you also use "drizzle-orm". Use only one package name.

3. **Code Fix for SQL Selects:**
   - Lines such as:
     ```typescript
     const pendingCount = await db.select({ count: sql<number>`count(*)` })
     ```
     can fail if `sql` or `PgColumn` is from an incompatible Drizzle ORM version.
   - Ensure both `db` and all helpers (`sql`, `eq`, etc.) come from the same module.

4. **Remove Protected Member Usage:**
   - Avoid direct type assertions or comparisons on ORM classes with protected/private members.

**Code suggestion:**
Most likely, updating your dependencies and ensuring consistent Drizzle ORM import will fix this error. After syncing dependencies:
```bash
pnpm remove drizzle-orm
pnpm add drizzle-orm@latest   # or your compatible version
pnpm install
```
Rebuild the project.

For deeper issues or if using monorepo, see the Drizzle ORM docs for [monorepo hoisting issues](https://orm.drizzle.team/docs/faq#monorepo).
