Solução direta
- Causa: o TypeScript está estourando com TS2589 ("Type instantiation is excessively deep") ao inferir tipos complexos do zodResolver + react-hook-form.
- Correção recomendada (rápida e segura): evitar que o compilador expanda os genéricos do resolver fazendo um cast para o tipo Resolver<T> do react-hook-form. Isso preserva a tipagem do formulário e elimina a recursão de tipos que causa o erro.
- Aplicar a mesma mudança em todas as páginas que usam useForm + zodResolver (apps/frontend-service e client copies mencionadas nos logs).

Alterações a aplicar (patches / snippets)
- Em cada arquivo, adicione a importação do tipo Resolver e altere a chamada useForm(...) para fazer o cast do resolver:
  import type { Resolver } from "react-hook-form";
  ...
  const form = useForm<YourFormType>({
    resolver: zodResolver(yourSchema) as unknown as Resolver<YourFormType>,
    defaultValues: { ... },
  });

Por que isso resolve
- O cast interrompe a inferência recursiva dos tipos do resolver, que é o que causa a profundidade excessiva dos tipos no tsc. O resultado: tsc para de gerar TS2589 e a tipagem de campos (generic T em useForm<T>) continua válida.

Alternativas / complementos
